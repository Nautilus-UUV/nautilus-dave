# Glider Nautilus Gazebo control

These commands use Gazebo Transport directly. They do not require the ROS
bridge. Run them after the `glider_nautilus` model has been spawned.

## Common command format

For a one-shot command:

```bash
gz topic \
  -t TOPIC \
  -m gz.msgs.Double \
  -p 'data: VALUE'
```

For continuous position control, publish repeatedly:

```bash
gz topic \
  -t TOPIC \
  -m gz.msgs.Double \
  -r 10 \
  -p 'data: VALUE'
```

Stop continuous publishing with `Ctrl+C`.

## Bladder volume

The bladder volume is commanded in cubic metres. The configured range is
`0.0` to `0.0025 m^3`.

### Empty the bladder

```bash
gz topic \
  -t /model/glider_nautilus/buoyancy_engine \
  -m gz.msgs.Double \
  -p 'data: 0.0'
```

### Set an intermediate volume

```bash
gz topic \
  -t /model/glider_nautilus/buoyancy_engine \
  -m gz.msgs.Double \
  -p 'data: 0.00125'
```

### Fill the bladder

```bash
gz topic \
  -t /model/glider_nautilus/buoyancy_engine \
  -m gz.msgs.Double \
  -p 'data: 0.0025'
```

The configured inflation rate is `0.0001 m^3/s`, so a full empty-to-full
change takes approximately 25 seconds.

### Monitor actual bladder volume

```bash
gz topic -e \
  -t /model/glider_nautilus/buoyancy_engine/current_volume
```

## ACU pitch

The pitch ACU is a prismatic joint with a position range of `-0.05975` to
`0.05975 m`.

Topic:

```text
/model/glider_nautilus/joint/ACU_pitch_joint/0/cmd_pos
```

### Move to the centre

```bash
gz topic \
  -t /model/glider_nautilus/joint/ACU_pitch_joint/0/cmd_pos \
  -m gz.msgs.Double \
  -p 'data: 0.0'
```

### Move toward the forward limit

```bash
gz topic \
  -t /model/glider_nautilus/joint/ACU_pitch_joint/0/cmd_pos \
  -m gz.msgs.Double \
  -p 'data: 0.05975'
```

### Move toward the aft limit

```bash
gz topic \
  -t /model/glider_nautilus/joint/ACU_pitch_joint/0/cmd_pos \
  -m gz.msgs.Double \
  -p 'data: -0.05975'
```

## Oil transfer

The oil transfer mass moves along the tank-to-bladder line. Position `0` is
the tank and position `0.376724037 m` is the bladder.

Topic:

```text
/model/glider_nautilus/joint/oil_transfer_joint/0/cmd_pos
```

### Move oil to the tank

```bash
gz topic \
  -t /model/glider_nautilus/joint/oil_transfer_joint/0/cmd_pos \
  -m gz.msgs.Double \
  -p 'data: 0.0'
```

### Move oil to the bladder

```bash
gz topic \
  -t /model/glider_nautilus/joint/oil_transfer_joint/0/cmd_pos \
  -m gz.msgs.Double \
  -p 'data: 0.376724037'
```

### Move oil to an intermediate position

```bash
gz topic \
  -t /model/glider_nautilus/joint/oil_transfer_joint/0/cmd_pos \
  -m gz.msgs.Double \
  -p 'data: 0.1883620185'
```

## Topic discovery and diagnostics

List the active Gazebo topics:

```bash
gz topic -l
```

List the control topics for this model:

```bash
gz topic -l | grep -E 'glider_nautilus/(buoyancy_engine|joint)'
```

Inspect a command topic and its subscribers:

```bash
gz topic -i \
  -t /model/glider_nautilus/joint/ACU_roll_joint/0/cmd_pos
```

Echo a command topic in a separate terminal:

```bash
gz topic -e \
  -t /model/glider_nautilus/joint/ACU_roll_joint/0/cmd_pos
```

The `/0/` segment is part of the controller topic generated by Gazebo and
must be included.
